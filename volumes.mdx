---
title: "Volumes"
---

Volumes store datasets, model weights, and outputs that need to persist beyond a single run. Their contents can be accessed directly through the SDK or mounted inside a function's runtime.

## Creating a volume

`client.create_volume()` creates a volume and returns a `VolumeHandle`. OuterProduct manages the underlying object storage by default.

```python
import outerproduct_sdk as op

client = op.init()
volume_handle = client.create_volume("datasets")
```

`client.get_volume()` returns a handle to an existing volume:

```python
volume_handle = client.get_volume("datasets")
```

## Reading and writing data

`VolumeHandle` provides methods for reading and writing objects through [obstore](https://developmentseed.org/obstore/). Paths are relative to the volume’s root.

```python
from pathlib import Path

volume_handle.put("training.csv", Path("training.csv"))

result = volume_handle.get("training.csv")
Path("downloaded.csv").write_bytes(bytes(result.bytes()))
```

`put()` accepts bytes, local files, and streams. `get()` returns a result whose contents can be read into memory with `.bytes()` or consumed as a stream.
