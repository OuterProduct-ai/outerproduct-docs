---
title: "Volumes"
---

Volumes store datasets, model weights, and outputs that need to persist beyond a single run. Their contents can be accessed directly through the SDK or mounted as files inside a function.

## Creating a volume

`client.create_volume()` creates a volume and returns a `VolumeHandle`. OuterProduct manages the underlying storage by default.

```python
import outerproduct_sdk as op

client = op.init()
volume_handle = client.create_volume("datasets")
```

`client.get_volume()` returns a handle to an existing volume:

```python
volume_handle = client.get_volume("datasets")
```

## Reading and writing data

`VolumeHandle` provides methods for reading and writing objects. Paths are relative to the volume’s root.
