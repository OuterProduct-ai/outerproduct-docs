title: "Introduction"
---

OuterProduct is an AI infrastructure platform powered by **Liquid Execution**. Liquid Execution lets you define what your application should do while OuterProduct manages where and how it runs. Liquid Execution is designed for workloads that are:

- **Wide:** Parallelize across many compute resources.
- **Deep:** Run as durable, long-lived sequences of steps that can recover from failures.
- **Heterogeneous:** Use different hardware and software environments within the same application.

Run anything, anywhere, for as long as it takes.

OuterProduct coordinates the compute, data, and execution required by these workloads. Your application can scale across available resources without embedding infrastructure-specific logic in its code.

This makes it possible to build applications such as:

- Multi-agent systems operating over large datasets, with automatic retries and fine-grained access to compute, data, and artifacts.
- Model training and hyperparameter searches distributed across GPUs, with managed checkpoints and evaluation artifacts.
- Long-running data and inference pipelines that resume after failures without repeating completed work.

With OuterProduct, you can run anything, anywhere, for as long as it takes.
