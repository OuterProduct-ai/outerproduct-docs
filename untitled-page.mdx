OuterProduct is an AI infrastructure platform powered by **Liquid Execution**. Liquid Execution lets you define what your application should do while OuterProduct manages where and how it runs. This form of execution is designed for workloads that are:

- **Wide:** Parallelize across many compute resources.
- **Deep:** Run durable, long-lived sequences of steps that can recover from failures.
- **Heterogeneous:** Use different hardware and software environments within the same application.

There is no more need to adapt your code to the underlying infrastructure. You can now run anything, anywhere, for as long as it takes. For now, this only works with arbitrary scripts in Python.

## What can you do with it?

Liquid Execution makes it possible to build applications such as:

- Multi-agent systems operating over large datasets, with automatic retries and fine-grained access to compute, data, and artifacts.
- Model training and hyperparameter searches distributed across GPUs, with managed checkpoints and evaluation artifacts.
- Long-running data and inference pipelines that resume after failures without repeating completed work.
