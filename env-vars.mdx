---
title: "Environment Variables"
---

Environment variables can be used to configure a function’s runtime environment. 

## Configuration

`client.run()` accepts environment variables through the `env_vars` dictionary: 

```python
run = client.run(
    fn=process_data,
    image=image,
    env_vars={
        "APP_LOG_LEVEL": "debug",
        "BATCH_SIZE": "32",
    },
)
```

Literal values, including numeric settings, must be provided as strings.

`client.map()` also accepts `env_vars`, applying the specified environment variables to every call it creates.

## Using secrets

`env_vars` also accepts stored OuterProduct [Secrets](/secrets) as values:

```python
hf_token = client.get_secret("huggingface-token")

run = client.run(
    fn=download_model,
    image=image,
    env_vars={"HF_TOKEN": hf_token},
)
```

At runtime, OuterProduct resolves the Secret and supplies its value to the environment as `HF_TOKEN`. The Secret must already exist, and the caller must have permission to access its value. 

Secrets can be created in the OuterProduct dashboard or through the SDK. See [Secrets](/secrets) for more information on creation and access management.
