---
title: "Environment Variables"
---

The `env_vars` parameter sets environment variables for your function's runtime environment. OuterProduct applies these variables at runtime, so calls using the same image can use different environment settings. 

## Configuration

`client.run()` accepts environment variables as a dictionary of names and string values. Numeric values must also be passed as strings, such as `"32"` rather than `32`.

```python
run = client.run(
    fn=process_data,
    image=image,
    env_vars={
        "APP_LOG_LEVEL": "debug",
        "BATCH_SIZE": "32",
    },
)
```

`client.map()` also accepts `env_vars`, and the same variables apply to every call it creates.

## Using secrets

Environment variable values can also reference stored OuterProduct [Secrets](/secrets), allowing credentials to be supplied without including sensitive values inline.

This example requires a Secret named `huggingface-token` containing your Hugging Face token. The caller must have permission to access its value.

```python
hf_token = client.get_secret("huggingface-token")

run = client.run(
    fn=download_model,
    image=image,
    env_vars={"HF_TOKEN": hf_token},
)
```

At runtime, OuterProduct resolves the Secret and supplies its value to the environment as `HF_TOKEN`. 

Secrets can be created in the OuterProduct dashboard or through the SDK. See [Secrets](/secrets) for more information on creation and access management.
