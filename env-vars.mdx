---
title: "Environment Variables"
---

The `env_vars` parameter can be used to set environment variables for your function. OuterProduct applies these variables at runtime, so the same image can be reused across calls with different environment settings. 

## Configuration

`client.run()` accepts environment variables as a dictionary of names and string values. Note that numeric values must be passed as strings

```python
run = client.run(
    fn=process_data,
    image=image,
    env_vars={"APP_LOG_LEVEL": "debug"},
)
```

`client.map()` also accepts `env_vars`, and the same variables apply to every call it creates.

## Using secrets

Environment variable values can also reference stored OuterProduct [Secrets](/secrets), allowing credentials to be supplied without including their values inline.

This example requires a Secret named `huggingface-token` containing your Hugging Face token. The caller must have permission to access its value.

```python
hf_token = client.get_secret("huggingface-token")

run = client.run(
    fn=download_model,
    image=image,
    env_vars={"HF_TOKEN": hf_token},
)
```

At runtime, OuterProduct resolves the Secret and supplies its value to the environment as `HF_TOKEN`. 

Secrets can be created in the OuterProduct dashboard or through the SDK. See [Secrets](/secrets) for more information on creation and access management.
