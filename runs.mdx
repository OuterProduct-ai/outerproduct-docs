title: "Runs"
---

A Run is an execution of your code on OuterProduct. It starts with a function call and includes any additional function calls launched from within it. Each call can have its own image, compute resources, and configuration.

## Runs, Calls, and Attempts

OuterProduct tracks execution at three levels:

- **Run:** The complete execution, including the initial function submitted with `client.run()` and any work it launches.
- **Call:** One function invocation submitted through the SDK, with its arguments and execution settings. Every Run starts with a root Call that could potentially launch child Calls.
- **Attempt:** One try at executing a Call. When a Call is retried, it receives another Attempt within the same Run. See the section on [Retries and Durability](/retries-and-durability) for more discussion of OuterProduct's execution guarantees.

A Run can contain many Calls, and each Call can have multiple Attempts. The OuterProduct dashboard shows this structure alongside execution status and logs.
