---
title: "Secrets"
---

Secrets store API keys, passwords, and cloud credentials. They can supply environment variables to functions and authenticate access to external object stores. Access is controlled through OuterProduct [Policies](/policies). 

## Creating a secret

Secrets can be created in the OuterProduct dashboard or through the SDK. `client.create_secret()` accepts a name and a `SecretValue`, and returns a `Secret` object.

This example stores a Hugging Face token as a generic Secret:

```python
import outerproduct_sdk as op

client = op.init()

secret = client.create_secret(
    "huggingface-token",
    value=op.SecretValue(generic=b"your-hugging-face-token"),
)
```

Generic values are stored as bytes. 

An existing Secret is available through `client.get_secret()`:

```python
secret = client.get_secret("huggingface-token")
```

The returned object contains metadata, including the Secret’s name, type, and version. It acts as a reference when configuring runs and volumes. Calling `get_secret()` does _not_ retrieve the stored value.

## Secret types

OuterProduct supports four Secret types:

<table>
  <colgroup>
    <col width="127" />
    <col width="765" />
  </colgroup>
  <thead>
    <tr>
      <th>Type</th>
      <th>Supported values</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>**Generic**</td>
      <td>Arbitrary bytes, such as API tokens and passwords.</td>
    </tr>
    <tr>
      <td>**AWS**</td>
      <td>Access keys, optionally with a session token, or an assume-role configuration referencing another AWS Secret.</td>
    </tr>
    <tr>
      <td>**Google Cloud**</td>
      <td>Service account keys or OAuth access tokens.</td>
    </tr>
    <tr>
      <td>**Azure**</td>
      <td>Storage account keys, SAS tokens, service principal credentials, or OAuth access tokens.</td>
    </tr>
  </tbody>
</table>

The type is determined by the `SecretValue` supplied during creation. Cloud credential types provide the structured information OuterProduct needs to authenticate with the corresponding provider.
