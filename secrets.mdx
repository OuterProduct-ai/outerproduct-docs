---
title: "Secrets"
---

Secrets store API keys, passwords, and cloud credentials. They can supply environment variables to functions and authenticate access to external object stores. Access is controlled through OuterProduct [Policies](/policies). 

## Creating a secret

Secrets can be created in the OuterProduct dashboard or through the SDK. `client.create_secret()` accepts a name and a `SecretValue`, and returns a `Secret` object.

This example stores a Hugging Face token as a generic Secret:

```python
import outerproduct_sdk as op

client = op.init()

secret = client.create_secret(
    "huggingface-token",
    value=op.SecretValue(generic=b"your-hugging-face-token"),
)
```

Generic values are stored as bytes. Here, `.encode()` converts the token to UTF-8.

An existing Secret is available through `client.get_secret()`:

```text
secret = client.get_secret("huggingface-token")
```

The returned object contains metadata, including the Secret’s name, type, and version. It acts as a reference when configuring runs and volumes; retrieving it does not retrieve the stored value.
